【重要】本ツールは2026年1月時点の公開データに基づくシミュレーションです。将来を保証するものではなく、最終的なキャリア決定はご自身の責任で行ってください。

【新機能】ネット検索機能について

データベースにない中小企業・非上場企業は「ネットで検索」ボタンで情報を推定できます。

サーバー起動方法（クリックで表示）

コマンドプロンプトで以下を実行:

cd C:\Users\roots
pip install -r requirements.txt
python company_search_server.py
